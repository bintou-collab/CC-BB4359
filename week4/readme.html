Happy Accident

I started my sketch as a star and my intention was to try to create a face but then as I started changing the size of the ellipses it made a cool pattern so I kept it. I used the map() function in order to have the shape of the ellipses change based on where the mouse was on the Y-axis which was very cool. I couldn't find a way to stop the drawing at a certain area so I can download the svg at the size I wanted the shape so I just moved the download button to the top of the canvas. I tried plotting the drawing 3 times. I had issues trying to put the marker in the plotter correctly but overall it was very cool to see the process. For the next assignment, I want to try that hypnotic pattern. It's something that I've seen on a book sleeve I had when I was younger.
